Pipeline Artifacts

  • docs/product-plan.md - Product vision (Stage 0)
  • docs/requirements.md - Requirements (Stage 1)
  • docs/design.md - Design doc (Stage 1)
  • docs/architecture.md - Architecture (Stage 2)
  • docs/review.md - Review verdict (Stage 3)
  • src/ - Implementation code (Stage 4)
  • reports/ - Test results (Stage 5-6)
  • dist/ - Final packages (Stage 8)

Deferred Questions System

  • Users can defer questions during ideation
  • "Revisit Later" option for any decision
  • Smart recommendations based on idea analysis
  • Per-project storage in project-config.json
  • Reminders at later stages (design, architect, implement)
  • Priority levels: low, medium, high, critical

Checkpoint & Recovery

  • State saved after each stage
  • Resume from any checkpoint
  • DLQ for permanently failed tasks
  • Circuit breakers after 5+ consecutive failures
  • Audit trail in docs/agent-audit.md
  • Pipeline state in docs/pipeline-state.md
