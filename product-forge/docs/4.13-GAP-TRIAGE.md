## Update (2026-09-12) — shortlist fixes applied
- **Layer order (2.1/2.3/2.5):** enforced in the code-agent directive — **DB → Logic → API → UI → integration** (dependency-first). (Correct order; `DB→UI→API` is wrong since UI consumes the API.)
- **Test traceability (3.5/3.8):** `nfr_coverage` now computes **FR-** and **NFR-** coverage (requirements referenced by tests); printed as `FR traceability` + `NFR coverage`.
- **Post-release smoke (8.3/8.4):** `nfr_runner.run_smoke` runs `test:smoke`/`smoke`/`test:sanity` when defined; included in packaging-mode verification.
- **Schema drift:** fixed — `pipeline-state.v1` accepts string/`current_stage` + string stage ids + `error` + extended statuses; `project-config.json` now includes `name`. Both validate.
- **0.5 / 5.6 / 6.6 / 9.1–9.3:** project `AGENTS.md`; architect `uiux_theme` section; secrets patterns in the code-quality gate; `document` required sections.
