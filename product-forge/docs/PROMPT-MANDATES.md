# Prompt Mandates Design

- Item: BI-PF-1542
- Scope: prompt wiring only

## Design/spec mandates

Design and specification prompts include:
1. requirement understanding and analysis
2. complete functional and technical design
3. 360° scenario and impact coverage
4. implementation and validation readiness
5. independent quality and completeness review

## Implementation mandates

Implement/fix prompts include:
1. understand and analyse completely
2. implement completely with no shortcuts
3. 360° impact and regression prevention
4. comprehensive validation
5. independent quality review and closure

Delivery states: Code Complete, Integration Complete, Validation Complete,
Quality Approved, Delivery Complete.

## Security

No caller-controlled security inputs are introduced. Prompts are read-only text.
