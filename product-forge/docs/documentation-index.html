SSOT rules (authority order)

  1. Implementation truth = the code - core/, core/orchestrator/, config/*.json, pipeline-definition.json. If a doc disagrees with code, code wins.
  2. Architecture/design SSOT = productforge_full_architecture.md.
  3. Agent prompt SSOT = .opencode/agent/*.md; agents_prompts_instructions.md mirrors them.
  4. Backlog SSOT = data/backlog/* via core/backlog.py.
  5. docs/archive/ is historical.

Implementation / adoption % = estimated share of the doc that exists in (or was adopted into) the codebase (100% = fully; 0% = analysis/planned). Historical plans/research/archive carry the % we adopted from them (so you can see we took from them and need not worry). not referenced = empty placeholder only.
