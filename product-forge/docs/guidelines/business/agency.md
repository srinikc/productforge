# Agency

## Overview
Professional services firm

## Core Processes
- Client acquisition and sales
- Project scoping and estimation
- Resource allocation and scheduling
- Project delivery and management
- Client communication and reporting
- Invoicing and payment collection

## Common Integrations
- HubSpot (CRM)
- Asana/Monday (project management)
- Slack (communication)
- Harvest (time tracking)
- QuickBooks (accounting)

## Key Metrics (KPIs)
- Utilization Rate
- Billable Hours
- Average Project Margin
- Client Retention Rate
- Revenue per Employee
- Sales Pipeline Value

## Compliance Requirements
- NDA/Confidentiality agreements
- GDPR (if EU clients)
- Industry-specific regulations

## Recommended Tech Stack
- **frontend**: React/WordPress
- **backend**: Node.js/PHP
- **database**: MySQL/PostgreSQL
- **hosting**: AWS/GCP
- **tools**: Various per client needs

## Common Pitfalls
1. Building features nobody uses
2. Ignoring user feedback
3. Underestimating time to market
4. Neglecting compliance requirements
5. Poor performance optimization
