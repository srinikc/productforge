# Consumer App

## Overview
B2C mobile and web applications

## Core Processes
- User registration and onboarding
- Core feature delivery
- User engagement and retention
- In-app purchases
- Push notifications
- Social sharing

## Common Integrations
- Firebase (analytics, notifications)
- Stripe (payments)
- Google/Apple Sign-In
- Mixpanel (analytics)
- Intercom (support)

## Key Metrics (KPIs)
- Daily Active Users (DAU)
- Monthly Active Users (MAU)
- Retention Rate (D1, D7, D30)
- Session Length
- In-app Purchase Revenue
- App Store Rating

## Compliance Requirements
- GDPR (if EU users)
- CCPA (if California users)
- COPPA (if children)
- App Store guidelines

## Recommended Tech Stack
- **frontend**: React Native/Flutter
- **backend**: Node.js/Python
- **database**: PostgreSQL/MongoDB
- **hosting**: AWS/GCP
- **notifications**: Firebase/APNs

## Common Pitfalls
1. Building features nobody uses
2. Ignoring user feedback
3. Underestimating time to market
4. Neglecting compliance requirements
5. Poor performance optimization
