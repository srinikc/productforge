# Hospitality & Travel

## Overview
Hotels, restaurants, and travel services

## Core Processes
- Reservation management
- Check-in/check-out
- Room/seat management
- Guest services
- Billing and invoicing
- Review management

## Common Integrations
- Booking.com/Expedia APIs
- Stripe (payments)
- Twilio (notifications)
- Google Maps
- TripAdvisor (reviews)

## Key Metrics (KPIs)
- Occupancy Rate
- Average Daily Rate (ADR)
- Revenue per Available Room (RevPAR)
- Guest Satisfaction Score
- Repeat Guest Rate
- Average Table Turnover

## Compliance Requirements
- PCI DSS (payments)
- GDPR (if EU guests)
- ADA accessibility
- Health regulations (restaurants)

## Recommended Tech Stack
- **frontend**: React/Next.js
- **backend**: Node.js/Python
- **database**: PostgreSQL
- **hosting**: AWS/GCP
- **pms**: Property Management System

## Common Pitfalls
1. Building features nobody uses
2. Ignoring user feedback
3. Underestimating time to market
4. Neglecting compliance requirements
5. Poor performance optimization
