# SaaS Business Model

## Overview
Software as a Service (SaaS) - cloud-based software delivered via subscription.

## Core Processes
- User registration and onboarding
- Subscription management
- Feature gating and tier management
- Usage tracking and billing
- Customer support and ticketing
- Churn prevention and retention

## Common Integrations
- Stripe (billing)
- Auth0 (authentication)
- Intercom (support)
- Segment (analytics)
- SendGrid (email)

## Key Metrics (KPIs)
- Monthly Recurring Revenue (MRR)
- Customer Acquisition Cost (CAC)
- Lifetime Value (LTV)
- Churn Rate
- Net Promoter Score (NPS)
- Active Users (DAU/MAU)

## Compliance Requirements
- GDPR (if EU users)
- SOC 2 (for enterprise)
- CCPA (if California users)

## Recommended Tech Stack
- Frontend: React/Next.js
- Backend: Node.js/Python
- Database: PostgreSQL
- Hosting: AWS/GCP
- Cache: Redis

## Common Pitfalls
1. Building features nobody uses
2. Ignoring churn until it's too late
3. Over-engineering early stage
4. Underpricing subscriptions
5. Neglecting customer support
