## 8. Recommendations by tier

### 8.1 Premium (paid — best quality)
- **Reasoning/architecture:** `claude-opus-5` / `gpt-5.6-sol` (Zen) or OpenRouter `anthropic/claude-opus-*`, `openai/gpt-5.*`.
- **Code:** `kimi-k2.7-code`, `deepseek-v4-pro` (Zen) or `qwen3.8-max`.
- **Balanced:** `claude-sonnet-5`, `gpt-5.5`.
- Requirements: tools + reasoning + large context. Use for `architect`, `implement`, `code-review`, `security`.

### 8.2 Cheap paid (budget, still capable)
- **Workhorse:** `deepseek-v4-flash` ($0.14/$0.28), `qwen3.8-flash`, `glm-5.3-flash`.
- **Cheap code:** `cohere/north-mini-code`, `poolside/laguna`, `deepseek-v4-flash`.
- **Cheap docs/analysis:** `gemini-3.5-flash-lite`, `gpt-5-nano`, `gpt-5.4-mini`.

### 8.3 OpenCode Go (paid, unified endpoint)
- **Planner/reasoner:** `mimo-v2.5-pro`, `gpt-5.6-luna`; **code:** `kimi-k2.7-code`, `deepseek-v4-pro`;
  **cheap:** `deepseek-v4-flash`, `qwen3.8-flash`; **vision:** `deepseek-v4-flash-vision-exp`.
- All reachable via `https://opencode.ai/zen/go/v1/chat/completions` with `OPENCODE_ZEN_API_KEY`.

### 8.4 OpenRouter paid
- **Frontier:** `anthropic/claude-sonnet-*`, `openai/gpt-5.*`, `google/gemini-3.*`, `x-ai/grok-4.*`.
- **Value code:** `qwen/qwen3.*-coder`, `deepseek/deepseek-v3.*`, `moonshotai/kimi-k2.*`, `z-ai/glm-*`.
- Use where OpenCode Zen lacks a model; one API key for 400+ models.

## 9. How to apply
- Edit `products/pipeline_dashboard/model-tier.json` → `profiles.free-trial` (per-agent `model` + `fallback_models`)
  and the base `agents`/`stages` blocks for the **actual** tier.
- Select at runtime: `PIPELINE_MODEL_TIER=free-trial` or `run_pipeline.py --tier free-trial`.
- Keep every referenced model in the profile's `models` map so it resolves to the correct provider/endpoint.
