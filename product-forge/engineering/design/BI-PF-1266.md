## 4. Logic invariants and state model
- PostgreSQL is the only event authority; events.jsonl is a read-only projection.
- Each tenant has a monotonic seq; cursor reads use (tenant_id, seq).
- A large payload is stored in object storage; the DB stores ref/sha256/size/content_type only.
- Event insert and outbox insert commit in one transaction.
- Only the Go event core writes events/outbox; no Python writer and no dual writer.
- Bus transports carry notifications, never domain truth.
- Ownership: core/events.py owns the read-only JSONL projection during migration; core/event_bus.py remains the compatibility facade; the Go event core owns PostgreSQL writes.
- Any compatibility projection is generated from PostgreSQL and cannot be written as authority.

## 6. Failure matrix
| Case | Expected behavior | Error code |
|---|---|---|
| DB unavailable during emit | Fail closed; no file fallback and no partial event. | EVENT_DB_UNAVAILABLE |
| Object store put fails for large payload | Fail closed before committing the event row. | EVENT_PAYLOAD_STORE_FAILED |
| Outbox dispatch fails | Retry at-least-once; dedupe by event_id; move to DLQ after limit. | EVENT_DELIVERY_FAILED |
| Cursor requested with unknown/future seq | Reject unknown/future cursor with EVENT_CURSOR_INVALID; cursor=0 returns from start; never cross-tenant. | EVENT_CURSOR_INVALID |
| Event DB commit fails after object put | Compensate/orphan-mark the object; GC only by explicit store tool; no event row visible. | EVENT_ORPHAN_CLEANUP |
| Retention deletes an object still referenced by a live event | Delete only when no live event row references the payload_ref; GC verifies reference count before object delete. | EVENT_PAYLOAD_STILL_REFERENCED |
| Outbox grows without dispatcher | Feature flag stays off or cleanup+row-count alert bounds growth; no silent accumulation. | EVENT_OUTBOX_UNBOUNDED |

## 8. Security, authz, tenant isolation
- Server-resolved tenant context; PostgreSQL RLS on event and outbox reads/writes.
- No provider URL as object identity; opaque refs + sha256.
- Webhook HMAC and idempotency key.
- Runtime roles are NOSUPERUSER/NOBYPASSRLS; RLS applies to all event/outbox access.
- Object references are tenant-scoped; provider URLs are never identity.

## 11. Compatibility, migration, rollout, rollback
- Design approval only in BI-PF-1266. Implementation starts at BI-PF-1267 contracts and BI-PF-1268 store/core.
Stop the Go writer first. Keep the last generated JSONL projection read-only with a freshness bound of 5 minutes; if older, mark the read path degraded and do not rebuild from Python. Restore the event authority from PostgreSQL PITR/backup when DB returns, regenerate the projection with the Go tool, verify cursor/outbox parity, then resume. Never let Python write authority.

## 13. Decisions and amendments
