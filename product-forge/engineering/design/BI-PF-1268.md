## 2. Requirements / acceptance criteria
- Go event core appends events to PostgreSQL with a per-tenant monotonic seq and an outbox row in the same transaction; cursor reads return exactly events with seq greater than the cursor.
- Large event payloads are stored in object storage; PostgreSQL stores only opaque ref, sha256, size and content type, and emit fails closed if storage fails.
- events.jsonl becomes a read-only compatibility projection; existing readers keep working and no second event authority or dual writer exists.
- Outbox writes are feature-flagged off/bounded until BI-PF-1269 dispatcher ships, with observable row-count limits.

## 3. Scope and non-goals
### In scope
- Go event core PostgreSQL append
- per-tenant seq/cursor
- object payload refs
- transactional outbox
- JSONL read-only projection
### Non-goals
- No dispatcher/transports in 1268
- No broker authority
- No breaking change to existing event readers
- No dual writer

## 4. Logic invariants and state model
- PostgreSQL is the sole event authority.
- seq is assigned per tenant in the DB transaction; no producer-supplied seq.
- Events and outbox rows commit atomically.
- events.jsonl is projection-only.
- Large payload bytes never live in PostgreSQL above threshold.

## 6. Failure matrix
| Case | Expected behavior | Error code |
|---|---|---|
| DB unavailable | event_append fails; no file fallback | EVENT_DB_UNAVAILABLE |
| object store failure for large payload | no event row commit | EVENT_PAYLOAD_STORE_FAILED |
| outbox disabled/unbounded | flag off + row-count alert/cleanup before enable | EVENT_OUTBOX_UNBOUNDED |
| cursor future/unknown | reject EVENT_CURSOR_INVALID; no cross-tenant | EVENT_CURSOR_INVALID |
| migration down without backup | refuse downgrade unless verified PITR/backup checkpoint exists | EVENT_MIGRATION_BACKUP_REQUIRED |
| orphan payload after failed commit | reconcile against event refs; GC only unreferenced objects | EVENT_ORPHAN_PAYLOAD |
| EVENT_OUTBOX_ENABLED=off | append event without outbox row; no dispatcher assumed | EVENT_OUTBOX_DISABLED |
| outbox rows exceed bound while dispatcher absent | Prune only delivered/failed rows; never delete pending/claimed. If pending exceeds limit, enable backpressure or keep flag off; alert operator. | EVENT_OUTBOX_BOUND_EXCEEDED |
