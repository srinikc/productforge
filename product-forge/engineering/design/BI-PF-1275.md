## 2. Requirements / acceptance criteria
- GET /api/v1/events/bus returns operational daemon status including running boolean flag, active PID, and uptime.
- POST /api/v1/events/bus/start launches the event bus daemon background process idempotently without duplicating running instances.
- POST /api/v1/events/bus/stop gracefully terminates the running bus daemon process and releases PID locks.
- GET /health envelope includes the event bus daemon operational state reporting ok or degraded.
- API access to bus management endpoints enforces authentication and operator role authorization.
