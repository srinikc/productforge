## 2. Requirements / acceptance criteria
- The GCS adapter streams/resumes large uploads (resumable upload for objects > 5 MB) instead of buffering the whole payload in memory, and validates the declared size.
- buildObjectStore() in go/edpsvc/main.go selects the GCS adapter via PF_OBJECT_BACKEND (config-only) with a real auth/token implementation, so the adapter is exercised end-to-end on the runtime path.
- A gated real-provider (creds) qualification run is documented and reproducible, so the GCS adapter can be marked production-qualified (mock conformance is not sufficient).

## 3. Scope and non-goals
### In scope
- GCS resumable upload session initiation and chunk streaming for objects > 5 MB
- On-the-fly SHA-256 calculation during streaming
- Size validation fail-closed enforcement
- buildObjectStore() wiring in edpsvc for PF_OBJECT_BACKEND=gcs
- Qualification documentation and test suite
### Non-goals
- Google Drive API support (separate backlog item BI-PF-1434)
- Azure Blob support (separate backlog item BI-PF-1433)
- Importing google-cloud-go heavy SDK

## 4. Logic invariants and state model
- Objects exceeding 5 MB threshold are streamed via resumable session and never fully buffered into a single byte slice.
- Total streamed bytes must match declared size; mismatch fails closed before finalizing object.
- Object checksum (pf-checksum metadata) is calculated accurately on the fly during streaming.
- buildObjectStore fails closed with clear error if PF_OBJECT_BACKEND=gcs but PF_GCS_BUCKET is empty.

## 8. Security, authz, tenant isolation
Tokens transmitted strictly via Authorization Bearer headers over HTTPS; credentials never logged; SHA-256 integrity verified.

## 9. Observability
GCS upload durations and chunk metrics emitted via standard edpsvc metrics counters.

## 10. Performance and scale
Constant memory footprint bounded to 5 MB buffer chunk regardless of total object size (supports gigabyte-scale artifacts).

## 11. Compatibility, migration, rollout, rollback
Opt-in via PF_OBJECT_BACKEND=gcs; default remains local storage.
Unset PF_OBJECT_BACKEND or set to 'local' / 's3'.

## 13. Decisions and amendments
- D-1435-1: Use 5 MB chunk size for resumable uploads, matching GCS recommended chunk multiple (256 KB * 20).
- D-1435-2: Stream data through an io.TeeReader to compute SHA-256 checksum concurrently with network transmission.
- D-1435-3: Keep small objects (<= 5 MB) on fast multipart upload path to avoid multiple round-trips.
