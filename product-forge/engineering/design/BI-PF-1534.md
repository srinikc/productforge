## 2. Requirements / acceptance criteria
- On-mode operations for an unlisted scope raise BACKLOG_DB_SCOPE_UNLISTED instead of reading or writing files
- On-mode write/delete/ID allocation for an unlisted scope fail closed with no file/Git fallback
- Explicit off mode keeps file authority for unlisted scopes
- Deterministic tests and runbook cover read/write/delete/ID paths and operator recovery
