## 2. Requirements / acceptance criteria
- AC-1: Prompt asset compiler tokenizes and encrypts persona definitions using AES-256-GCM authenticated cipher with runtime key derivation.
- AC-2: Shipped customer packages contain zero readable system prompt files or plaintext markdown instructions in distributions.
- AC-3: Runtime agent adapter transparently decrypts and loads compiled prompt bundles in memory with zero plaintext disk leakage.

## 4. Logic invariants and state model
- Decrypted plaintext prompts exist only in volatile heap memory; never written to filesystem.
- Tampered ciphertext bundles fail closed immediately upon authentication tag check.
- Key derivation incorporates salt and domain separation context (HKDF-SHA256).

## 5. Contracts
### API
Offline CLI and Go library; no external HTTP routes exposed.
### Database / persistence
No relational database dependencies required for asset compilation.
### Files / stores / config
Compiles raw markdown prompts into encrypted .pfa binary bundle with magic bytes PFA1.
PF_PROMPT_KEY (minimum 32 bytes) and PF_PROMPT_BUNDLE file location path.

## 8. Security, authz, tenant isolation
AES-256-GCM authenticated encryption with 96-bit random nonce and 128-bit authentication tag; zero disk leakage.

## 9. Observability
Structured logs recording bundle compilation time, input count, payload size, and bundle SHA-256 digest.

## 10. Performance and scale
Sub-10ms bundle decryption latency for complete 50-persona catalog.

## 11. Compatibility, migration, rollout, rollback
Stage 1: Go cipher package. Stage 2: Build CLI compiler. Stage 3: Packaging integration and verification tests.
Disable prompt compilation flag in packaging pipeline to revert to raw asset packaging.
