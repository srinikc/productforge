## 2. Requirements / acceptance criteria
- AC-1: Web console build pipeline compiles SPA frontend into optimized HTML/JS/CSS assets with content hashing and integrity checks.
- AC-2: Go platform server embeds compiled frontend assets via go:embed and serves them with HTTP cache headers and gzip compression.
- AC-3: Shipped customer packages contain zero Node.js runtime dependencies or raw TypeScript/JSX source files.

## 4. Logic invariants and state model
- SPA history fallback serves index.html for client-side routing while missing static assets return 404.
- Hashed static chunks receive immutable cache headers; index.html receives no-cache headers.
- Customer editions fail closed if any raw source (.ts, .tsx, .jsx, .mts, .cts), source maps (*.map), Node manifests (package.json, lockfiles), or node_modules directory is present.
- SPA fallback strictly excludes /api/*, /health, and /metrics paths; unmatched API requests return 404 JSON, preserving downstream API error contracts.
- Embed-time integrity attestation: NewConsoleHandler verifies embedded asset SHA256 hashes against embedded checksums.txt on startup, failing closed on tampering.

## 8. Security, authz, tenant isolation
Guarantees zero proprietary source code disclosure and zero Node.js runtime vulnerabilities by compiling frontend to immutable minified chunks embedded in Go binary with traversal boundary protection.

## 9. Observability
Standard HTTP access metrics, structured packaging failure codes (RAW_FRONTEND_SOURCE_DETECTED, NODE_MODULES_DETECTED, ASSET_INTEGRITY_MISMATCH), and checksum manifests.

## 10. Performance and scale
Sub-millisecond static response times from in-memory embed.FS and 65-80% payload reduction via transparent gzip compression.

## 11. Compatibility, migration, rollout, rollback
Shipped in Go platform binary with additive EAP manifest registration.
Serve web console from external static directory via configuration flag env:PF_CONSOLE_STATIC_DIR without binary rebuild.

## 13. Decisions and amendments
- DEC-1553-01: Go standard library embed.FS selected as canonical binary asset embedding mechanism.
- DEC-1553-02: Hard fail-closed rejection of node_modules, source maps (*.map), and .ts/.tsx in customer packaging to protect intellectual property.
- DEC-1553-03: Language rule compliance under AGENTS.md Rule 17: Extending existing shipped Python module core/packaging.py is permitted under the 60-line growth threshold, while all new shipped runtime logic and HTTP handling is authored in Go (go/web/console.go). Build-time asset compilation is tooling/packaging orchestration.
