## 2. Requirements / acceptance criteria
- AC-1: Helm chart deploys complete Product Forge platform stack including PostgreSQL with pgvector, object store, and core API pods.
- AC-2: Terraform module automates cloud VPC, managed Kubernetes cluster, and database provisioning across AWS and GCP providers.
- AC-3: Single command deployment script provisions infrastructure, deploys Helm chart, and passes automated post-deploy health check in under 10 minutes.

## 4. Logic invariants and state model
- INV-01: Persistent volume claims and HA database instances must retain data and survive workload rollback (reclaimPolicy: Retain)
- INV-02: Pods run as non-root with dropped Linux capabilities and restricted privileges
- INV-03: Cloud provisioning must support warm cluster deployments (<10m) and cold multi-cloud cluster rollouts (<25m)
