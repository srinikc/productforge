## 2. Requirements / acceptance criteria
- AC-1: Memory Orchestrator intercepts and validates all memory reads, writes, and searches.
- AC-2: SQL/storage filters guarantee zero cross-tenant and cross-project data leakage.
- AC-3: Four negative leakage test suites verify boundary isolation under concurrent load.

## 3. Scope and non-goals
### In scope
- Go memory gateway go/pfmemory
- Authenticated Scope and ACL enforcement
- edpsvc /memory handler wiring
- Four negative leakage suites
### Non-goals
- New public memory API
- Python orchestrator
- Consolidation (BI-PF-1569)
- Lifecycle governance (BI-PF-1570)
- Schema migration

## 4. Logic invariants and state model
- No cross-tenant or cross-project data exposure
- Caller cannot choose authoritative tenant/project
- Denied access is indistinguishable from not found
- Writes require canonical validation
- Search and batch sizes are bounded
