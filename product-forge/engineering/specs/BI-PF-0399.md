# Functional Spec — BI-PF-0399 — A5: Runtime Dependency Compiler

- **Version:** 1
- **Status:** approved
- **Owner:** Srinikc
- **Source:** BI-PF-0399
- **Functional SHA:** pending
- **Linked design:** engineering/design/BI-PF-0399.md

## 1. Outcome
Product Forge platform A5 Runtime Dependency Compiler (RDC) operational: authoritative native Go engine with Python seam client that composes EAP manifests, target OS/architectures (linux/amd64, linux/arm64, windows/amd64, darwin/arm64), deployment profiles, and license/entitlement profiles into a standalone runtime package composition, enforced by a fail-closed IP-leakage guard that refuses any composition for customer/commercial editions that contains unprotected raw .py source files.

## 2. Actors
- platform release maintainer
- security engineer
- customer deployment operator
- packaging CI/CD automation agent

## 3. Scope
- go/pfcore/rdc.go
- go/pfcore/rdc_test.go
- go/pfcore/pfcore.go
- core/rdc.py
- api/routers/packaging.py
- sample-runtime-package/runtime-composition.json
- test-framework/tests/pipeline/test_a5_rdc.py

## 4. Non-goals
- Full runtime process orchestration (handled by agent runtime and process supervisor)
- Dynamic code generation (handled by product compiler stages)
- Replacing EAP manifest generation (handled by A4 core/packaging.py:eap_build)

## 5. Assumptions and dependencies
- Target OS/architectures for v1: linux/amd64, linux/arm64, windows/amd64, darwin/arm64.
- Customer editions (enterprise, on-prem, saas, oem) strictly forbid raw .py files; community/dev may allow raw .py when declared.
- BI-PF-0393: A1 wire contract & contracts schema.
- BI-PF-0397: A4 EAP manifest schema and registry.
- BI-PF-0398: A3 compiled packaging pipeline and NO-RAW-.py release gate.

## 6. Domain and glossary
- RDC: Runtime Dependency Compiler
- EAP: Edition/Artifact Package manifest
- IP-leakage guard: fail-closed validator that verifies zero raw Python sources in customer editions
- Target platform: OS/arch tuple (e.g. linux/amd64, windows/amd64)
- Runtime Composition: structured manifest declaring binaries, libraries, configs, and assets required at runtime

## 7. Functional requirements
### FR-1 — Deterministic Multi-Target Runtime Composition
- **priority:** P0
- **source:** BI-PF-0399
- **preconditions:** EAP manifest built or loaded; target OS/arch and license profile specified.
- **trigger:** Execution of RDC composition via CLI, API, or build pipeline.
- **inputs:** eap (dict), target_os (str), target_arch (str), license_tier (str)
- **outputs:** runtime composition dictionary declaring included components, binary artifacts, native libraries, configs, and requirements.
- **errors:** Unsupported OS/arch, invalid EAP, or missing dependencies fails composition with ERR_RDC_INVALID_INPUT.
- **auth:** operator / platform admin token
- **idempotency:** Identical inputs produce byte-for-byte deterministic composition outputs.
- **data_rules:** All paths normalized with forward slashes; component versions and hashes stamped.
- **edge_cases:** Handling cross-compilation target platforms and architectures.
- **acceptance:** Given valid EAP and target OS/arch, RDC outputs complete runtime package plan.
- **verification:** test-framework/tests/pipeline/test_a5_rdc.py::test_rdc_multi_target_composition

### FR-2 — Fail-Closed IP-Leakage Guard
- **priority:** P0
- **source:** BI-PF-0399
- **preconditions:** Runtime composition candidate generated.
- **trigger:** Invocation of rdc.validate_ip before package assembly or distribution.
- **inputs:** composition manifest and list of included file paths/extensions
- **outputs:** validation result: {valid: bool, unmet: list[str], ip_zone: str}
- **errors:** Customer edition containing raw .py files returns valid=False with IP_LEAKAGE_RAW_PY.
- **auth:** internal / operator
- **idempotency:** Read-only inspection; deterministic validation result.
- **data_rules:** Enterprise, on-prem, saas, oem must have 0 .py files; all logic compiled to .pyd/.so or native binaries.
- **edge_cases:** Handling doc files or python files in test fixtures (must not be included in customer runtime).
- **acceptance:** Any composition including raw Python for customer editions is strictly refused.
- **verification:** test-framework/tests/pipeline/test_a5_rdc.py::test_rdc_ip_leakage_guard_refusal

### FR-3 — Native Go Wire Seam Dispatch
- **priority:** P0
- **source:** BI-PF-0399
- **preconditions:** Native pfcore-host binary available.
- **trigger:** WireRequest with op="rdc.compose" or op="rdc.validate_ip".
- **inputs:** WireRequest envelope containing RDC payload.
- **outputs:** WireResponse envelope with composition result.
- **errors:** Malformed request returns ok=False error response.
- **auth:** internal wire seam
- **idempotency:** Pure function execution.
- **data_rules:** Adheres strictly to A1 WireRequest and WireResponse contracts.
- **edge_cases:** pfcore-host rebuild on demand when binary is absent.
- **acceptance:** Wire requests dispatch cleanly through pfcore.go to rdc.go functions.
- **verification:** go test ./go/pfcore -run TestRDC

### FR-4 — Canonical sample-runtime-package Fixture
- **priority:** P1
- **source:** BI-PF-0399
- **preconditions:** Sample EAP fixture available.
- **trigger:** Fixture generation and test verification.
- **inputs:** sample.eap fixture
- **outputs:** sample-runtime-package/ directory with runtime-composition.json
- **errors:** Fixture generation failure stops test suite.
- **auth:** dev / test
- **idempotency:** Deterministic output.
- **data_rules:** Conforms to ComponentManifest and BOM contracts.
- **edge_cases:** Verified on Windows, Linux, and macOS.
- **acceptance:** sample-runtime-package/ fixture validates against canonical contracts.
- **verification:** test-framework/tests/pipeline/test_a5_rdc.py::test_sample_runtime_package_fixture

### FR-5 — REST API Surface
- **priority:** P1
- **source:** BI-PF-0399
- **preconditions:** Packaging router mounted in FastAPI app.
- **trigger:** HTTP POST to /api/v1/packaging/rdc/compose or /api/v1/packaging/rdc/validate.
- **inputs:** JSON payload with EAP and target parameters.
- **outputs:** JSON response with composition or validation details.
- **errors:** 400 for invalid inputs, 403 for unauthorized, 422 for unprocessable entity.
- **auth:** Bearer token with operator/admin role.
- **idempotency:** POST operations are safe read/compute workflows.
- **data_rules:** Standard envelope wrapping.
- **edge_cases:** Large EAP payloads within standard 1MB request limits.
- **acceptance:** Endpoints respond with valid runtime composition or validation status.
- **verification:** test-framework/tests/pipeline/test_a5_rdc.py::test_rdc_api_endpoints
