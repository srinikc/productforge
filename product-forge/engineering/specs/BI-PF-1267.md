## 7. Functional requirements
### FR-1 — Versioned event envelope with seq and payload reference
- **priority:** P0
- **source:** BI-PF-1267
- **preconditions:** A producer emits an event.
- **trigger:** Contract validation runs.
- **inputs:** Envelope fields.
- **outputs:** Validated envelope v2.
- **errors:** CONTRACT_INVALID; CONTRACT_VERSION_UNSUPPORTED.
- **auth:** Tenant/actor fields present.
- **idempotency:** event_id required.
- **data_rules:** Additive fields only.
- **edge_cases:** Unknown version and missing field.
- **acceptance:** Given an envelope When required fields are present Then Python and Go accept the same shape.
- **verification:** Contract parity tests in BI-PF-1267.

### FR-2 — Subscription, alert-rule and webhook contracts
- **priority:** P0
- **source:** BI-PF-1267
- **preconditions:** Consumer or webhook is registered.
- **trigger:** Subscription/alert/webhook payload is validated.
- **inputs:** Target, filter, channels, body.
- **outputs:** Validated contract plus HMAC headers.
- **errors:** WEBHOOK_SIGNATURE_INVALID; CONTRACT_INVALID.
- **auth:** auth_ref and tenant context.
- **idempotency:** X-PF-Idempotency-Key = event_id.
- **data_rules:** No secrets in payload.
- **edge_cases:** Replay and signature mismatch.
- **acceptance:** Given a webhook contract When headers and body are validated Then signature and event_id idempotency headers are present; runtime delivery/dedupe belongs to BI-PF-1270.
- **verification:** Contract/header shape tests in BI-PF-1267; runtime delivery tests in BI-PF-1270.

## 16. Open questions
- Unknown top-level envelope fields are rejected; vendor data must use extensions{}; no silent coercion.
- seq is assigned by the Go/PostgreSQL event core, never by producers; per-tenant monotonic increasing, gaps allowed, never reused; cursor uses seq > cursor, not occurred_at.
- BI-PF-1267 owns webhook payload/header contract and constant-time verifier test; BI-PF-1270 owns runtime delivery and calls that verifier.
- WEBHOOK_HMAC_KEY_REF is a secret reference, never the key; webhook-enabled startup fails closed when missing.
- BI-PF-1267 guarantees event_id and idempotency header shape; runtime dedupe belongs to BI-PF-1270.
- Python/Go parity tests must cover missing/invalid seq, cursor ordering, unknown version, and signature verification.
