## 7. Functional requirements
### FR-1 — Append event with per-tenant seq and outbox
- **priority:** P0
- **source:** BI-PF-1268
- **preconditions:** DB and tenant context available.
- **trigger:** event_append A1 call.
- **inputs:** Canonical envelope.
- **outputs:** Event row + outbox row.
- **errors:** EVENT_DB_UNAVAILABLE; no file fallback.
- **auth:** Server-resolved tenant; RLS.
- **idempotency:** Unique event_id.
- **data_rules:** Atomic event+outbox.
- **edge_cases:** Retry duplicate.
- **acceptance:** Given a valid event When appended Then exactly one row gets a monotonic tenant seq and an outbox row.
- **verification:** go/pfcore/eventstore_pg_test.go

### FR-2 — Store large payload by object reference
- **priority:** P0
- **source:** BI-PF-1268
- **preconditions:** Payload > threshold.
- **trigger:** event_append.
- **inputs:** Payload bytes.
- **outputs:** ref/sha256/size/content_type.
- **errors:** EVENT_PAYLOAD_STORE_FAILED.
- **auth:** Object tenant boundary.
- **idempotency:** sha256 content.
- **data_rules:** No large bytes in DB.
- **edge_cases:** Object store down.
- **acceptance:** Given oversized payload When appended Then DB stores reference and sha256 and no event row without it.
- **verification:** go/pfcore/eventstore_pg_test.go

### FR-3 — Cursor returns events after seq
- **priority:** P0
- **source:** BI-PF-1268
- **preconditions:** Events exist.
- **trigger:** event_read.
- **inputs:** tenant and since_seq.
- **outputs:** events seq>cursor.
- **errors:** EVENT_CURSOR_INVALID.
- **auth:** Tenant scoped.
- **idempotency:** Deterministic order.
- **data_rules:** seq order only.
- **edge_cases:** Unknown/future cursor.
- **acceptance:** Given cursor N When read Then exactly events with seq>N for that tenant, enforced by UNIQUE(tenant_id,seq).
- **verification:** go/pfcore/eventstore_pg_test.go

### FR-4 — JSONL read-only projection
- **priority:** P0
- **source:** BI-PF-1268
- **preconditions:** Legacy readers exist.
- **trigger:** Projection refresh.
- **inputs:** PostgreSQL events.
- **outputs:** Read-only JSONL.
- **errors:** Projection stale marked.
- **auth:** Read-only.
- **idempotency:** Regeneration deterministic.
- **data_rules:** No writer to JSONL authority.
- **edge_cases:** PostgreSQL down.
- **acceptance:** Given PostgreSQL events When the Go event core regenerates the projection Then JSONL is read-only and matches DB.
- **verification:** test-framework/tests/pipeline/test_event_core.py
