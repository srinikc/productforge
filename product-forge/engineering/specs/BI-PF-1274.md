## 7. Functional requirements
### FR-1 — SSE Event Streaming Endpoint
- **priority:** P0
- **source:** BI-PF-1274
- **preconditions:** FastAPI application initialized with event router.
- **trigger:** Client issues GET /api/v1/events/stream.
- **inputs:** project; since; event_type
- **outputs:** StreamingResponse with text/event-stream chunks
- **errors:** 401 Unauthorized for unauthenticated clients.
- **auth:** authenticate
- **idempotency:** Read-only streaming endpoint
- **data_rules:** SSE format: event, data JSON, double newline
- **edge_cases:** Client disconnect closes stream generator
- **acceptance:** Given an authenticated client, when requesting /events/stream, then live SSE events are streamed.
- **verification:** test-framework/tests/pipeline/test_events_sse_api.py::test_events_stream_sse_format

### FR-2 — Backlog Event Replay via Since Parameter
- **priority:** P1
- **source:** BI-PF-1274
- **preconditions:** Historical events exist in project event store.
- **trigger:** GET /api/v1/events/stream provided with since query parameter.
- **inputs:** since ISO timestamp
- **outputs:** Replay of historical events matching since filter
- **errors:** Graceful handling of empty or future timestamp.
- **auth:** authenticate
- **idempotency:** Deterministic replay of historical events
- **data_rules:** Events sorted by occurred_at / seq
- **edge_cases:** No events matching timestamp emits keepalive comment
- **acceptance:** Given since timestamp, when connecting to stream, then past events after since are emitted first.
- **verification:** test-framework/tests/pipeline/test_events_sse_api.py::test_events_stream_since_replay

### FR-3 — Event Subscription Creation & Listing
- **priority:** P0
- **source:** BI-PF-1274
- **preconditions:** Operator has valid authentication credentials.
- **trigger:** POST /api/v1/events/subscriptions or GET /api/v1/events/subscriptions.
- **inputs:** id; transport; event_types; target; filter
- **outputs:** Subscription object with stored confirmation
- **errors:** 400 ApiError if required fields missing or transport invalid.
- **auth:** require_operator
- **idempotency:** POST upserts subscription by ID
- **data_rules:** Transport must be one of: sse, webhook, inproc, notify
- **edge_cases:** Duplicate ID overwrites existing subscription
- **acceptance:** Given valid subscription payload, when POST is called, then subscription is stored and queryable.
- **verification:** test-framework/tests/pipeline/test_events_sse_api.py::test_subscription_create_and_list

### FR-4 — Subscription Patch & Deletion
- **priority:** P1
- **source:** BI-PF-1274
- **preconditions:** Subscription exists in registry.
- **trigger:** PATCH or DELETE /api/v1/events/subscriptions/{subscription_id}.
- **inputs:** subscription_id; patch fields
- **outputs:** Updated subscription or deletion confirmation
- **errors:** 404 ApiError if subscription not found on PATCH.
- **auth:** require_operator
- **idempotency:** DELETE is idempotent; PATCH updates specified fields
- **data_rules:** Tenant isolation enforced on mutations
- **edge_cases:** Deleting non-existent subscription returns deleted=false
- **acceptance:** Given existing subscription, when PATCH/DELETE called, then state changes accordingly.
- **verification:** test-framework/tests/pipeline/test_events_sse_api.py::test_subscription_patch_and_delete

### FR-5 — Subscription Contract & Authorization Validation
- **priority:** P0
- **source:** BI-PF-1274
- **preconditions:** Client request received by API boundary.
- **trigger:** API request with missing fields or invalid permissions.
- **inputs:** HTTP request headers and body
- **outputs:** Enveloped ApiError response
- **errors:** 400 VALIDATION_FAILED, 401 UNAUTHORIZED, 403 FORBIDDEN.
- **auth:** authenticate / require_operator
- **idempotency:** Fail-closed validation
- **data_rules:** Error envelopes conform to API-1 standard
- **edge_cases:** Malformed JSON payload
- **acceptance:** Given invalid payload or missing auth, when route invoked, then standard error envelope returned.
- **verification:** test-framework/tests/pipeline/test_events_sse_api.py::test_subscription_validation_errors
