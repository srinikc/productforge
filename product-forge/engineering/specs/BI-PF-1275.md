## 7. Functional requirements
### FR-1 — Event Bus Daemon Status Query
- **priority:** P0
- **source:** BI-PF-1275
- **preconditions:** API service is active.
- **trigger:** GET /api/v1/events/bus
- **inputs:** tenant_id (optional)
- **outputs:** status object with running, pid, uptime_seconds, and status
- **errors:** 401 UNAUTHORIZED if token missing
- **auth:** authenticate
- **idempotency:** Read-only idempotent query
- **data_rules:** Returns running=false and pid=null when inactive
- **edge_cases:** Dead PID lock file cleaned and reported as running=false
- **acceptance:** Given inactive daemon, when GET /events/bus called, returns running=false.
- **verification:** test-framework/tests/pipeline/test_events_bus_daemon_api.py::test_ac1_bus_status_query

### FR-2 — Event Bus Daemon Start Operation
- **priority:** P0
- **source:** BI-PF-1275
- **preconditions:** Caller holds operator role.
- **trigger:** POST /api/v1/events/bus/start
- **inputs:** request body (optional)
- **outputs:** result object with ok, pid, already_running
- **errors:** 401 UNAUTHORIZED, 403 FORBIDDEN if not operator
- **auth:** require_operator
- **idempotency:** Idempotent start: if already running, returns already_running=true
- **data_rules:** Spawns daemon process under single-writer PID lock
- **edge_cases:** Multiple concurrent starts serialize cleanly under PID lock
- **acceptance:** Given stopped daemon, when POST /start called, launches process and returns pid.
- **verification:** test-framework/tests/pipeline/test_events_bus_daemon_api.py::test_ac2_start_daemon_idempotent

### FR-3 — Event Bus Daemon Stop Operation
- **priority:** P0
- **source:** BI-PF-1275
- **preconditions:** Caller holds operator role.
- **trigger:** POST /api/v1/events/bus/stop
- **inputs:** request body (optional)
- **outputs:** result object with ok and stopped PID list
- **errors:** 401 UNAUTHORIZED, 403 FORBIDDEN if not operator
- **auth:** require_operator
- **idempotency:** Idempotent stop: if stopped, returns stopped=[]
- **data_rules:** Terminates daemon process and cleans PID lock file
- **edge_cases:** Process already dead returns stopped=[] and cleans lock
- **acceptance:** Given running daemon, when POST /stop called, terminates process and clears lock.
- **verification:** test-framework/tests/pipeline/test_events_bus_daemon_api.py::test_ac3_stop_daemon_graceful

### FR-4 — Health Check Component Reporting
- **priority:** P1
- **source:** BI-PF-1275
- **preconditions:** API service is active.
- **trigger:** GET /health
- **inputs:** 
- **outputs:** system health envelope with event_bus entry
- **errors:** 
- **auth:** public/anonymous
- **idempotency:** Read-only idempotent query
- **data_rules:** event_bus reports ok or degraded
- **edge_cases:** Unreachable daemon reports degraded without failing whole system health
- **acceptance:** Given healthy API, when GET /health called, envelope includes event_bus component.
- **verification:** test-framework/tests/pipeline/test_events_bus_daemon_api.py::test_ac4_health_integration

### FR-5 — Operator Authorization Enforcement
- **priority:** P0
- **source:** BI-PF-1275
- **preconditions:** Request received by API boundary.
- **trigger:** Calls to bus mutation endpoints with non-operator credentials.
- **inputs:** Authorization headers
- **outputs:** 401 or 403 ApiError standard envelope
- **errors:** 401 UNAUTHORIZED, 403 FORBIDDEN
- **auth:** authenticate / require_operator
- **idempotency:** Fail-closed access rejection
- **data_rules:** Standard API error structure
- **edge_cases:** Invalid token format
- **acceptance:** Given unauthenticated call, when POST /start called, returns 401 error envelope.
- **verification:** test-framework/tests/pipeline/test_events_bus_daemon_api.py::test_ac5_bus_auth_operator_enforcement
