## 1. Outcome
- Operators can inspect authoritative backlog authority state before/while workers depend on it.

## 2. Actors
- platform operator
- edpsvc
- worker
- HIL

## 3. Scope
- GET /admin/backlog/authority
- BacklogStore.Authority
- migration 0018 counter
- Prometheus rule/runbook
- scope guard

## 4. Non-goals
- No data mutation from the readiness endpoint
- No PF-GP pipeline change

## 5. Assumptions and dependencies
- backlog_items uses forced RLS
- allocation/reservation tables are global
- admin token is configured
- BI-PF-1314 EDP-22
- BI-PF-1478 T3 tenant isolation for scale-out

## 6. Domain and glossary
- authority=global
- item_scope=tenant
- reservation_scope=global
- tenant required for item count

## 7. Functional requirements
### FR-1 — Auth-first authority endpoint
- **priority:** Must
- **source:** AC-1
- **preconditions:** edpsvc running
- **trigger:** GET/POST /admin/backlog/authority
- **inputs:** bearer token; tenant
- **outputs:** 401 without token; 405 for POST with token
- **errors:** 401 UNAUTHENTICATED; 405 METHOD_NOT_ALLOWED
- **auth:** PF_ADMIN_TOKEN/adminOnly
- **idempotency:** read-only
- **data_rules:** no DB query before auth
- **edge_cases:** POST without bearer
- **acceptance:** Given no bearer When any method is called Then 401.; Given a bearer and POST When called Then 405.
- **verification:** go test ./... -run TestBacklogAuthority

### FR-2 — Return authoritative counts
- **priority:** Must
- **source:** AC-2
- **preconditions:** valid token; migration 0016/0018 applied
- **trigger:** GET with tenant
- **inputs:** tenant
- **outputs:** authority=global,next_id,reservation_scope=global,reservation_count,tenant,item_scope=tenant,item_count
- **errors:** 503 authority unavailable
- **auth:** adminOnly
- **idempotency:** read-only
- **data_rules:** item_count tenant-scoped via forced RLS
- **edge_cases:** missing allocation row
- **acceptance:** Given valid token and tenant When GET Then 200 with authority fields.; Given missing allocation row When GET Then 503.
- **verification:** go test ./... -run TestBacklogAuthorityWithDB

### FR-3 — Tenant is mandatory
- **priority:** Must
- **source:** AC-3
- **preconditions:** valid token
- **trigger:** GET without tenant
- **inputs:** missing tenant
- **outputs:** 400
- **errors:** 400 tenant required
- **auth:** adminOnly
- **idempotency:** read-only
- **data_rules:** never query backlog_items without tenant
- **edge_cases:** tenant empty
- **acceptance:** Given no tenant When GET Then 400 and no item query.
- **verification:** go test ./... -run TestBacklogAuthorityRequiresTenant

### FR-4 — Fail closed on authority loss
- **priority:** Must
- **source:** AC-4
- **preconditions:** migration or DB fault
- **trigger:** authority read/startup check
- **inputs:** DB state
- **outputs:** fixed 503 message
- **errors:** backlog-authority-unavailable
- **auth:** adminOnly
- **idempotency:** read-only
- **data_rules:** no zeroed 200; no Git/local fallback
- **edge_cases:** missing migration; missing row; timeout
- **acceptance:** Given missing migration/row or DB outage When authority is read Then 503 fixed message.
- **verification:** go test ./... -run "TestBacklogAuthority(FailsClosed|Missing)"

### FR-5 — Counter and scope proof
- **priority:** Must
- **source:** AC-5
- **preconditions:** migration 0018 applied
- **trigger:** reservation mutations / scope guard
- **inputs:** reservations; candidate files
- **outputs:** counter parity and no out-of-scope paths
- **errors:** counter drift; scope violation
- **auth:** DB trigger + CI guard
- **idempotency:** trigger idempotent
- **data_rules:** counter covers insert/delete/update/truncate
- **edge_cases:** out-of-scope file; interrupted migration
- **acceptance:** Given reservation mutations When counter is read Then it matches.; Given a modified path outside affected_files When guard runs Then it fails.
- **verification:** go test ./... -run TestBacklogReservationCounter; python -m pytest test-framework/tests/test_pf_sb_scope_guard.py
