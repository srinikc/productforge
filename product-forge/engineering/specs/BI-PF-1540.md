## 7. Functional requirements
### FR-1 — Record HIL material-change decisions
- **priority:** P0
- **source:** BI-PF-1540
- **preconditions:** A review budget decision or delta base must be validated.
- **trigger:** An operator posts a MATERIAL_CHANGE decision.
- **inputs:** decision payload; expected revision
- **outputs:** item.decisions appended
- **errors:** VALIDATION_FAILED; NOT_FOUND; CONFLICT; DEPENDENCY_UNAVAILABLE
- **auth:** operator role; HIL actor fixed by config and bound to authenticated token
- **idempotency:** revision guard
- **data_rules:** scope/project resolved by _scope_project; no tenant header
- **edge_cases:** stale revision; missing HIL
- **acceptance:** Given HIL approval, when posted, then the decision is stored append-only.
- **verification:** pytest tests/test_review_material_change.py

### FR-2 — Accept reviewed-ancestor delta base
- **priority:** P0
- **source:** BI-PF-1540
- **preconditions:** A review budget decision or delta base must be validated.
- **trigger:** A re-review supplies a since SHA.
- **inputs:** since SHA; reason
- **outputs:** budget exemption or refusal
- **errors:** refuse unreviewed/non-ancestor
- **auth:** review tooling only
- **idempotency:** deterministic ancestry check
- **data_rules:** base must be a reviewed head and ancestor of HEAD; reason must cite latest review sha
- **edge_cases:** arbitrary SHA
- **acceptance:** Given a reviewed ancestor, when re-review runs, then full-review budget is not consumed.
- **verification:** pytest tests/test_review_material_change.py

### FR-3 — Expose decision API contract
- **priority:** P0
- **source:** BI-PF-1540
- **preconditions:** A review budget decision or delta base must be validated.
- **trigger:** API docs are generated.
- **inputs:** route metadata
- **outputs:** OpenAPI path
- **errors:** missing route
- **auth:** operator-only
- **idempotency:** idempotent schema export
- **data_rules:** route documented
- **edge_cases:** no auth
- **acceptance:** Given the app, when OpenAPI is generated, then the decisions route is present.
- **verification:** pytest tests/test_review_material_change.py::test_decisions_api_route_exists
