## 7. Functional requirements
### FR-1 — Design/spec mandates
- **priority:** P0
- **source:** BI-PF-1542
- **preconditions:** Agent prompt is assembled.
- **trigger:** design/spec agent builds prompt
- **inputs:** backlog item
- **outputs:** prompt with five design mandates
- **errors:** missing mandate blocks prompt
- **auth:** prompt assembly only
- **idempotency:** prompt build read-only
- **data_rules:** all five mandates present
- **edge_cases:** no design pack
- **acceptance:** Given a design agent prompt, when assembled, then all five design mandates are present.
- **verification:** pytest tests/test_prompt_mandates.py

### FR-2 — Implementation mandates
- **priority:** P0

- **preconditions:** Agent prompt is assembled.

- **outputs:** prompt with five implementation mandates and control contract
- **errors:** missing mandate blocks prompt
- **auth:** prompt assembly only
- **idempotency:** prompt build read-only
- **data_rules:** all five mandates present
