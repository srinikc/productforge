# Functional Spec — BI-PF-1550 — Prompt and Persona Asset Compiler: secure compilation and runtime encryption for proprietary agent instructions

- **Version:** 1
- **Status:** approved

## 1. Outcome
Proprietary agent personas, reasoning instructions, and role contracts compiled into encrypted binary asset bundles (.pfa) with zero readable plaintext prompts in commercial customer distributions.

## 2. Actors
- Platform Asset Compiler
- EAP Packaging Pipeline
- Agent Runtime Loader
- Platform Entitlement Engine

## 3. Scope
- go/promptcompiler/
- scripts/dev/prompt_compiler.py
- core/packaging.py
- test-framework/tests/pipeline/test_prompts_compiler.py

## 4. Non-goals
- Public foundation model weights encryption
- User conversational chat session encryption
- Hardware-enclave execution guarantees

## 5. Assumptions and dependencies
- Standard AES-256-GCM authenticated cipher with HKDF key derivation is the cryptographic standard
- Decryption key is derived from the installation entitlement key / environment master key
- Commercial packages fail closed if raw unencrypted markdown prompt files are detected in distribution payloads
- ADR-0001: Compiled commercial packaging without raw source
- BI-PF-0387: Single-source delivery baseline (Go runtime)
- BI-PF-0398: A3 compiled packaging pipeline and release gates

## 6. Domain and glossary
- Intellectual Property Protection
- Asset Tokenization and Compilation
- In-Memory Decrypt-on-Invocation

## 7. Functional requirements
### FR-1 — Prompt asset compiler tokenizes and encrypts persona definitions using AES-256-GCM authenticated cipher
- **priority:** Must
- **source:** AC-1
- **preconditions:** Proprietary agent prompt files and master key present
- **trigger:** Execution of prompt compiler CLI or packaging pipeline step
- **inputs:** Directory of prompt files, persona definitions, master key string
- **outputs:** Encrypted binary asset bundle with header, nonce, auth tag, and payload
- **errors:** ERR_COMPILER_EMPTY_INPUT; ERR_INVALID_KEY_DERIVATION
- **auth:** Platform build pipeline authentication
- **idempotency:** Deterministic ciphertext generation with reproducible HKDF info
- **data_rules:** AES-256-GCM 96-bit nonce and 128-bit authentication tag; Strict SHA-256 integrity verification
- **edge_cases:** Corrupted header or altered auth tag aborts decryption fail-closed
- **acceptance:** Given a directory of agent prompt definitions, When the prompt compiler executes, Then persona definitions are compiled into an encrypted asset bundle using AES-256-GCM.
- **verification:** pytest test-framework/tests/pipeline/test_prompts_compiler.py -k test_compiler_aes_encryption

### FR-2 — Shipped customer packages contain zero readable system prompt files or plaintext markdown instructions
- **priority:** Must
- **source:** AC-2
- **preconditions:** Package build directory populated
- **trigger:** Package verification gate execution prior to release artifact sealing
- **inputs:** Output distribution directory
- **outputs:** Verification pass report or leakage failure list
- **errors:** ERR_PLAINTEXT_PROMPT_LEAK
- **auth:** Packaging release gate context
- **idempotency:** Read-only inspection of package filesystem
- **data_rules:** Zero unencrypted .md prompt files or plaintext persona JSON in commercial outputs
- **edge_cases:** Nested subdirectories or zip archives inspected recursively
- **acceptance:** Given a compiled commercial distribution package, When the packaging leakage scanner runs, Then zero plaintext system prompt files or readable instructions are found.
- **verification:** pytest test-framework/tests/pipeline/test_prompts_compiler.py -k test_zero_plaintext_leakage

### FR-3 — Runtime agent adapter transparently decrypts and loads compiled prompt bundles in memory with zero disk leakage
- **priority:** Must
- **source:** AC-3
- **preconditions:** Encrypted bundle file and valid runtime entitlement key present
- **trigger:** Agent runtime initialization requesting persona or instruction text
- **inputs:** Encrypted bundle stream or file path, runtime key
- **outputs:** In-memory agent persona instructions and prompt dictionary
- **errors:** ERR_DECRYPT_KEY_MISMATCH; ERR_BUNDLE_TAMPERED
- **auth:** Internal runtime authorization
- **idempotency:** Decryption is stateless and can be invoked repeatedly
- **data_rules:** Decrypted prompt memory retained only in heap; zero disk scratch writes
- **edge_cases:** Tampered ciphertext raises authenticated cipher error immediately
- **acceptance:** Given an encrypted prompt bundle, When agent runtime loads persona instructions, Then decrypted text is loaded directly in memory without writing temporary files to disk.
- **verification:** pytest test-framework/tests/pipeline/test_prompts_compiler.py -k test_in_memory_decryption

## 9. Configuration contract
| Name | Default | Precedence | Valid values | Empty behavior | Invalid behavior | Startup validation |
|---|---|---|---|---|---|---|
| PF_PROMPT_KEY | pf-prompt-master-key-32-chars-ok! | env > config | >= 32 character key string | generates deterministic local development key | ERR_INVALID_KEY_LENGTH | compiler.validate_key |
| PF_PROMPT_BUNDLE | assets/prompts.pfa | env > config | valid file path ending in .pfa or .bin | defaults to assets/prompts.pfa | file open error | compiler.validate_bundle_path |

## 10. Non-functional requirements
- Sub-10ms bundle decryption latency for complete 50-persona catalog
- Zero scratch disk writes during runtime decryption

## 11. Data lifecycle
- Encrypted asset bundles versioned alongside releases
- Plaintext memory cleared upon agent execution termination

## 12. Compatibility
- Go 1.22+
- Python 3.10+

## 13. Rollback behavior
- Disable prompt compilation in packaging flags to fall back to standard asset packaging.

## 14. Observability
- Structured logs recording compilation duration, asset counts, and bundle SHA-256
- Audit log events on decryption failures or tampered bundle detection
