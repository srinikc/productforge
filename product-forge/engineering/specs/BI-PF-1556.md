# Functional Specification: Automated Deployment Rollback Orchestration: trigger instant rollback and record evidence on failed post-deploy smoke tests

- Item: `BI-PF-1556`
- Frozen SHA: `9a2edf45d19c`
- Candidate SHA: `088b3dfd`

## Requirements

- **FR-1**: AC-1: Post-deployment smoke test runner executes automated health, database connectivity, and core API verification immediately after deployment.
- **FR-2**: AC-2: Any failing smoke test assertion automatically triggers instant rollback to prior healthy revision within 30 seconds.
- **FR-3**: AC-3: Rollback orchestration records comprehensive failure evidence, diagnostic logs, and incident report in deployment evidence ledger.

## Rollback

Manual operator override to force deployment retention.

## Config Contract

```json
{
  "retry_threshold": 3,
  "rollback_timeout_seconds": 30,
  "health_check_endpoint": "/api/v1/health"
}
```
