# Functional Specification: Canonical Memory Record Contract: schema definition, 6-type taxonomy classification, and storage mapping

- Item: `BI-PF-1566`
- Frozen SHA: `4ea883304044`
- Candidate SHA: `a55d2fc5`

## Requirements

- **FR-1**: Define canonical MemoryRecord struct in Go (go/memory/record.go) with JSON snake_case tags and strict types: ID (UUID string validated via uuid.Parse), TenantID (mandatory string), ProjectID (mandatory string), Kind (enum MemoryKind), Scope (string), Authority (enum AuthorityTier), Provenance (struct ProvenanceInfo), Content (string inline payload), PayloadRef (optional URI string for out-of-band large storage validated for standard schemes like s3:// or https://), Confidence (float64 0.0-1.0), ValidFrom (time.Time formatted/parsed as UTC ISO8601), ValidUntil (*time.Time optional UTC ISO8601), SupersededBy (optional UUID string validated via uuid.Parse), Tags ([]string bounded by max_tags=50), EmbeddingRef (optional string), Embedding ([]float32 bounded by configurable max_embedding_dimensions=3072), Evidence (struct MemoryEvidence with strictly typed fields: Source, EventID, RecordedBy, Signature), Metadata (map[string]any bounded by max 50 entries, strictly enforced at validation layer to scalar primitives only: string, float64, bool, int64; any composite map/slice rejected with ErrInvalidMetadataScalar).
- **FR-2**: Enforce 6 canonical memory kinds (working, semantic, episodic, procedural, prospective, external) in Go; unknown kinds must fail closed with ErrInvalidKind.
- **FR-3**: Define canonical 8-to-6 legacy mapping table in config/memory_legacy_mapping.json: short_term->working, working_memory->working, long_term_fact->semantic, concept->semantic, session_event->episodic, conversation_turn->episodic, execution_step->procedural, workflow_rule->procedural. Go implements authoritative MapLegacyType using embedded mapping; core/agent_memory.py provides a thin Python adapter loading the same JSON file to prevent logic drift.
- **FR-4**: Enforce UTC ISO8601 timestamps and validate temporal ordering using native time.Time: when ValidUntil is present, ValidFrom must be strictly before ValidUntil (ValidFrom.Before(*ValidUntil)).
- **FR-5**: Enforce immutable non-empty tenant_id and project_id on all MemoryRecords at validation layer. Cross-record referential integrity (ensuring SupersededBy belongs to the same tenant) is designed for the persistence layer via tenant-bound repository queries.
