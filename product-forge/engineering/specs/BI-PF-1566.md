## 7. Functional requirements
### FR-1 — Canonical MemoryRecord Go Contract with Strict Field Types
- **priority:** Must
- **source:** AC-1
- **preconditions:** MemoryRecord instance supplied
- **trigger:** Validation invocation via record.Validate()
- **inputs:** MemoryRecord struct instance
- **outputs:** nil on valid record or typed error
- **errors:** ErrInvalidID; ErrMissingTenant; ErrMissingProject; ErrEmptyPayload; ErrPayloadTooLarge; ErrInvalidMetadataScalar
- **auth:** Tenant and project context required
- **idempotency:** Validation execution is strictly idempotent
- **data_rules:** Valid UUID v4 ID; Mandatory tenant_id and project_id; 1MB maximum content size
- **edge_cases:** Self-referencing superseded_by pointer rejected
- **acceptance:** Given valid MemoryRecord instance, When Validate is called, Then nil is returned without errors.
- **verification:** go test -v ./go/memory -run TestMemoryRecord_Validate

### FR-2 — 6-Kind Taxonomy with Fail-Closed Validation
- **priority:** Must
- **source:** AC-2
- **preconditions:** MemoryKind string value supplied
- **trigger:** Kind classification check via ValidateMemoryKind()
- **inputs:** MemoryKind value
- **outputs:** nil on valid kind or ErrInvalidKind
- **errors:** ErrInvalidKind
- **auth:** Internal domain check
- **idempotency:** Taxonomy validation is strictly idempotent
- **data_rules:** One of: working, semantic, episodic, procedural, prospective, external
- **edge_cases:** Unknown or unmapped kind strings fail closed
- **acceptance:** Given memory kind string, When validated against canonical taxonomy, Then only approved 6 kinds succeed.
- **verification:** go test -v ./go/memory -run TestMemoryKind

### FR-3 — 8-to-6 Legacy Type Consolidation Mapping Matrix
- **priority:** Must
- **source:** AC-3
- **preconditions:** Legacy memory type string provided
- **trigger:** Taxonomy translation via MapLegacyType()
- **inputs:** Legacy memory type string
- **outputs:** Canonical MemoryKind and slice of legacy tags
- **errors:** ErrUnknownLegacyType
- **auth:** Internal domain check
- **idempotency:** Mapping lookup is strictly idempotent
- **data_rules:** Mapping table backed by config/memory_legacy_mapping.json
- **edge_cases:** Unknown legacy type strings return ErrUnknownLegacyType
- **acceptance:** Given legacy memory type, When MapLegacyType is executed, Then canonical 6-kind taxonomy equivalent is returned.
- **verification:** go test -v ./go/memory -run TestMapLegacyType

### FR-4 — Temporal Bounds and UTC Invariant Enforcement
- **priority:** Must
- **source:** AC-4
- **preconditions:** valid_from and optional valid_until timestamps provided
- **trigger:** Temporal bounds verification via ValidateTemporalBounds()
- **inputs:** ValidFrom time.Time and ValidUntil *time.Time
- **outputs:** nil on valid bounds or ErrInvalidTemporalBounds
- **errors:** ErrInvalidTemporalBounds
- **auth:** Internal domain check
- **idempotency:** Temporal comparison is strictly idempotent
- **data_rules:** ValidUntil if non-nil must satisfy ValidFrom < ValidUntil
- **edge_cases:** ValidFrom equals ValidUntil returns ErrInvalidTemporalBounds
- **acceptance:** Given temporal timestamps, When bounds are verified, Then valid_from must be strictly before valid_until.
- **verification:** go test -v ./go/memory -run TestTemporalBounds

### FR-5 — Tenant Isolation and Identity Invariant Enforcement
- **priority:** Must
- **source:** AC-1
- **preconditions:** tenant_id and project_id strings provided
- **trigger:** Tenant validation check via ValidateTenant()
- **inputs:** TenantID and ProjectID strings
- **outputs:** nil on valid tenant/project or typed error
- **errors:** ErrMissingTenant; ErrMissingProject
- **auth:** Tenant context enforcement
- **idempotency:** Tenant boundary validation is strictly idempotent
- **data_rules:** TenantID and ProjectID must match ^[a-zA-Z0-9_.:-]+$
- **edge_cases:** Whitespace-only or empty tenant ID rejected
- **acceptance:** Given tenant context strings, When boundary is validated, Then non-empty compliant IDs succeed.
- **verification:** go test -v ./go/memory -run TestMemoryRecord_TenantIsolation
