Risk Assessment

Technical Risks - R-1: Real-time streaming scale (high): Many concurrent projects × agents × logs can overwhelm naive streaming. Mitigation: multiplexing, backpressure, pagination, and log sampling strategies; load-test with target concurrency. - R-2: Backend/dashboard contract drift (medium): UI depends on pipeline internals that evolve. Mitigation: API-first contract, versioned endpoints, contract tests. - R-3: Voice reliability in-browser (medium): TTS/STT and wake-word accuracy vary by browser/OS. Mitigation: feature-detect, graceful fallback to text, clear enabled/disabled state per F-29. - R-4: Mobile scope creep (medium): Attempting full desktop parity on mobile. Mitigation: explicitly scope mobile to monitoring, alerts, input responses, and light control. - R-5: Auto mode failure handling (medium): Unattended runs can fail or loop. Mitigation: guardrails, retry policy, abort conditions, and prominent alerting.

Product & UX Risks - R-6: Dialog overload (medium): Too many modals degrade UX. Mitigation: consistent dialog patterns, non-blocking where possible, notification center over popup spam. - R-7: Complexity for new users (medium): Rich controls can overwhelm. Mitigation: sensible defaults, tier presets, progressive disclosure, onboarding. - R-8: AI/voice trust (medium): Users may not trust chat/voice to control real runs. Mitigation: confirmations for destructive actions, transparent action log.

Operational & Business Risks - R-9: Deployment topology mismatch (medium): Split backend/dashboard introduces CORS, auth, and networking complexity. Mitigation: document and support both topologies (F-40/F-41), default to simplest. - R-10: API surface duplication (low-medium): Rebuilding pipeline APIs in the dashboard creates drift. Mitigation: perform explicit reuse analysis (F-43) and prefer reuse + thin additions. - R-11: Security of broad control surface (medium): One place that controls everything is a high-value target. Mitigation: authn/authz, TLS, secret handling per cross-cutting guidelines, audit logging of control actions. - R-12: Scope breadth (high): Very large surface (web + mobile + voice + tests + deployment + API). Mitigation: phase delivery — portfolio/orchestration first, then companion/voice, then mobile and analytics — with clear must-have vs. nice-to-have boundaries.
