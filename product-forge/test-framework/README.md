# Test Automation Framework

Multi-project, pipeline-level test framework for QA of generated products.

## Overview

This framework provides automated testing for products generated by the multi-agent pipeline. It handles:

- **Product Deployment** - Docker and local install support
- **Test Execution** - Run test suites (smoke, sanity, daily, weekly, full)
- **Defect Tracking** - Log and track defects
- **Root Cause Analysis** - Determine which stage could have prevented defects
- **Agent Integration** - Auto-update prevention rules for pipeline agents
- **Dashboard** - Web UI for metrics, trends, and regression detection

## Quick Start

### 1. Install Dependencies

```bash
cd test-framework
pip install -r requirements.txt
```

### 2. Start Dashboard

```bash
python dashboard/app.py
```

Access at http://localhost:3011
- Username: `admin`
- Password: `admin123`

### 3. Configure Products

Edit `config/projects.yaml` to add products:

```yaml
projects:
  myproduct:
    name: "My Product"
    type: "product"
    domain: "productivity"
    path: "../products/myproduct"
    deployment:
      method: "local"
      install: "npm install"
      start: "npm run dev"
      health_check: "http://localhost:3000"
    test_categories:
      unit: true
      api: true
      e2e: true
      visual: true
```

## Test Suites

| Suite | Duration | When to Run |
|-------|----------|-------------|
| smoke | 5-10 min | After deployment |
| sanity | 15-30 min | After major changes |
| daily | 30-60 min | Every night |
| weekly | 2-4 hours | Every weekend |
| full | 4-8 hours | Before release |

## Test Categories

- **unit** - Unit tests for individual components
- **api** - API endpoint tests
- **integration** - Integration tests between components
- **e2e** - End-to-end user flow tests
- **visual** - Visual regression tests
- **performance** - Performance and load tests
- **security** - Security vulnerability tests
- **install** - Install/uninstall/upgrade tests

## Core Modules

### ProductDeployer

```python
from core.deployer import ProductDeployer

deployer = ProductDeployer(project_config)
result = deployer.deploy()  # Docker or local
deployer.stop()
deployer.uninstall()  # optional
```

### TestRunner

```python
from core.runner import TestRunner

runner = TestRunner(config)
result = runner.run_suite("myproduct", "smoke", project_config)
print(f"Passed: {result.passed}, Failed: {result.failed}")
```

### DefectTracker

```python
from core.defect_tracker import DefectTracker, Severity

tracker = DefectTracker("myproduct")
defect = tracker.log_defect(
    title="Login fails",
    description="API returns 500",
    severity=Severity.HIGH,
    test_id="test_login",
    test_name="test_login_api",
    suite_name="smoke"
)
```

### RCCAAnalyzer

```python
from core.rcca import RCCAAnalyzer

analyzer = RCCAAnalyzer()
report = analyzer.analyze_defect("DEF-001", defect_data)
# Auto-updates agent prevention rules
```

### AgentIntegration

```python
from core.agent_integration import AgentIntegration

integration = AgentIntegration()
integration.append_prevention_rule("implement", "Add input validation", "DEF-001")
history = integration.get_agent_prevention_history("implement")
```

## RCCA Flow

```
Test Fails → Defect Logged → RCCA Analysis
                              ↓
                    Determine Stage + Agent
                              ↓
                    Generate Prevention Rule
                              ↓
                    Auto-Update Agent .md File
```

3. Framework automatically:
   - Deploys product
   - Runs appropriate test suite
   - Logs defects
   - Analyzes root causes
   - Updates agent prevention rules

## Customization

### Add New Test Category

1. Add to `config/test-suites.yaml`:
```yaml
categories:
  accessibility:
    description: "Accessibility tests"
    tools: ["axe-core"]
```

2. Create template in `templates/accessibility/`
3. Add to project config in `projects.yaml`

### Add New Deployment Method

1. Add method to `core/deployer.py`
2. Update project config:
```yaml
deployment:
  method: "kubernetes"
```

### Modify RCCA Rules

Edit analysis patterns in `core/rcca.py`:
```python
analysis_rules = {
    "test_patterns": {
        r"test_.*_accessibility": {
            "category": RootCauseCategory.DESIGN,
            "stage": PipelineStage.DESIGN,
            "agent": "design"
        }
    }
}
```

## Integration with Pipeline

The test framework integrates with the multi-agent pipeline:

1. **Pipeline generates product** → adds to `projects.yaml`
2. **Validate agent** → runs test suite via framework
3. **Defects logged** → tracked in defect tracker
4. **RCCA analyzes** → determines root cause stage
5. **Agent updated** → prevention rules added to `.md` file
6. **Fix agent** → fixes defects based on severity
7. **Dashboard shows** → metrics, trends, regressions
